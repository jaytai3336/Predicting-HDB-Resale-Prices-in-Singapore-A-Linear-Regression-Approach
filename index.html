01. Methodology

Model & Feature Analysis

Data Source
Official HDB resale transaction data from data.gov.sg — covering all flat types across Singapore towns with transaction dates, floor area, storey range, and remaining lease.
Feature Engineering
One-hot encoding for town and flat type. Storey midpoint extraction from storey range strings. Lease commencement date converted to remaining lease years. Log transformation for price.
Regression Analysis
OLS with statsmodels. Diagnostic tests: VIF for multicollinearity, Breusch-Pagan for heteroscedasticity, Jarque-Bera for normality of residuals. F-statistic confirms overall model significance.
Key Findings
Floor area and remaining lease are the strongest predictors. Central locations command a premium of ~25–35%. Each additional storey level adds approximately SGD 3–5K.
